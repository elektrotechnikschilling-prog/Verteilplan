# Verteilerplan-App · Elektrotechnik Schilling

Wandelt den in Craftnote ausgefüllten Aufnahmebogen direkt im Browser in den fertigen
Verteilerplan (Stromkreisverzeichnis) um. Der Plan lässt sich bearbeiten und als PDF speichern.

- Läuft komplett auf dem Gerät: Es werden keine Daten hochgeladen oder gespeichert.
- In diesem Repository liegen nur Programmcode, Logo und Firmendaten – keine Kundendaten.

App: https://elektrotechnikschilling-prog.github.io/Verteilplan/
